The diner conversation

Eve's conversational mode is engineered around a continuous-listening loop with smart silence detection, audio-context unlocking, and barge-in interruption. Once the user enters the conversation, the mic stays open between turns until a plan executes.

  1. User clicks Tell Eve → Web Speech API starts streaming partial transcripts to the browser.
  2. The recognizer fires onresult on every partial. We track lastSpeechAt on a useRef (state would be stale inside the silence interval).
  3. If 2.5s elapse with no new partial AND the transcript is non-empty, we stop the recognizer and POST the transcript to /api/eve-parse-intent.
  4. Server-side, Gemini Flash extracts {location, vibe, party, dietary, budget, cuisine, freeText}, decides if it has enough to plan, and writes a one-line spoken reply in Eve's voice.
  5. The reply is synthesized via Cloud TTS Chirp 3 HD and played in the <audio> element. The audio context was unlocked on the user's first pointerdown, so play() succeeds.
  6. If isComplete → execute the plan (4 parallel API calls: 3 stop-image + 1 narration). If not, the mic re-opens for the user's follow-up. Conversation loops.
  7. The user can interrupt Eve mid-speech; the recognizer's onresult handler pauses Eve's audio when fresh speech arrives.

The marketplace flywheel

  1. Restaurant lands on /restaurant, sets brand once. Cuisine is inferred from name + city via Google Search if blank.
  2. /api/suggest-special Search-mines recent Yelp / Google / blog reviews of THIS restaurant. If specific dish praise found → that's tonight's special. Otherwise pivots to current trend research + recommends real competitor restaurants.
  3. /api/content-pack generates the full multi-platform kit in one call: AI-illustrated Instagram post, three-scene Reel with voiceover script + audio, brand-voiced menu card, email subject + body, and an SMS blurb.
  4. Owner clicks Publish to Eve diners → dish enters the POSTED_SPECIALS in-memory index.
  5. A diner asking Eve for an evening that night in the same city gets the special suggested with an Eve Originals badge — driving foot traffic.
